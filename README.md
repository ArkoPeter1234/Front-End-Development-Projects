# Web Development Internship – Auspify Technologies

## Overview

This repository contains the projects I completed during my **4-week remote Web Development Internship with Auspify Technologies**.

The internship focused on practical learning and hands-on development using **HTML, CSS, JavaScript, responsive design, UI/UX principles, APIs, and modern web development techniques**.

The program required interns to complete at least **4 out of 6 projects**. I successfully completed **all 6 projects**, covering different levels of web development from responsive websites to more advanced web applications.

## Projects Completed

### 1. Responsive Landing Page

A responsive landing page developed using HTML, CSS, and JavaScript.

The project focused on creating a clean and engaging interface with responsive sections, navigation, call-to-action buttons, interactive elements, animations, and mobile-friendly layouts.

**Skills:** HTML, CSS, JavaScript, Responsive Web Design, UI Development.

### 2. Personal Portfolio Website

A professional portfolio website designed to showcase personal skills, projects, achievements, and contact information.

The website includes sections for personal information, projects, skills, and contact details, with a responsive design suitable for different screen sizes.

**Skills:** HTML, CSS, JavaScript, Responsive Design, Form Handling, Website Deployment.

### 3. Weather Forecast Website

A dynamic weather application that retrieves weather information using a public weather API.

Users can search for a city and view current weather information and forecasts. The project also includes dynamic data handling, loading states, and error handling.

**Skills:** JavaScript, Fetch API, API Integration, JSON, Dynamic Web Development.

### 4. Online Quiz Application

An interactive quiz application where users can answer multiple questions and receive their scores and results automatically.

The project demonstrates how JavaScript can be used to manage questions, capture user responses, calculate scores, and dynamically update the interface.

**Skills:** JavaScript, DOM Manipulation, Application Logic, User Interaction, Front-End Development.

### 5. E-Commerce Website

A functional e-commerce website designed to demonstrate the main features of an online shopping platform.

The project includes product listings, product search, shopping cart functionality, order management, checkout-related functionality, and client-side data storage.

**Skills:** Advanced JavaScript, Local Storage, E-Commerce Development, Application Logic, UI/UX Design.

### 6. Online Learning Platform

A complete online learning platform designed to manage courses, lessons, student enrollment, learning progress, and certificates.

The platform includes student, instructor, and administrator interfaces, with features such as authentication, course management, enrollment, progress tracking, dashboards, and certificate functionality.

**Skills:** Advanced Web Development, Authentication, Application Architecture, Course Management, Progress Tracking.
