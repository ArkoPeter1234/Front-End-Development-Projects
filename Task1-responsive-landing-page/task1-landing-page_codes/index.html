Task workflow

Five steps, one landing page

  1. 01

    Design the layout

    A hero with a clear thesis, a features grid, a workflow timeline, and a contact section — each with one job.

  2. 02

    Build responsive sections

    CSS Grid and Flexbox reflow the hero, cards and footer down to a single column below 720px.

  3. 03

    Add navigation & CTAs

    A sticky nav with a mobile hamburger toggle, and a primary "Request a demo" button that appears in three places.

  4. 04

    Implement animations

    An on-load route trace in the hero, plus scroll-triggered reveals powered by the Intersection Observer API.

  5. 05

    Optimise for mobile

    Touch-sized tap targets, a collapsing nav, and typography that scales with clamp() instead of fixed breakpoints.
